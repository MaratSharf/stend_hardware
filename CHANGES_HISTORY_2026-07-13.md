# История изменений — 13 июля 2026

## Версия 4.7.0

### Исправление критичных проблем безопасности и стабильности

#### Безопасность
- **Убран пароль из `config.yaml`** — пароль БД и SECRET_KEY теперь хранятся только в `.env`
- Создан `.env.example` с шаблоном переменных
- Обновлены документация и скрипты инициализации БД

#### Производительность
- **Connection pool для БД** — заменено создание нового соединения на каждый запрос на `psycopg2.pool.ThreadedConnectionPool`
- Настройки пула через переменные окружения: `DB_POOL_MIN`, `DB_POOL_MAX`

#### Архитектура
- **Устранено дублирование кода сценариев** — общие методы:
  - `_trigger_measurement()` — триггер камеры с проверкой состояния
  - `_set_lamps()` / `_reset_lamps()` — управление лампами
  - `_handle_result_lamps()` — установка ламп по результату OK/NG

- **Отображение текущего сценария** на экране мониторинга:
  - Новый блок "СЦЕНАРИЙ" в панели управления
  - Новый API endpoint `/api/scenario_status`

#### Обработка ошибок
- **Критические ошибки останавливают систему** — добавлены кастомные исключения:
  - `CriticalError` — базовый класс
  - `HardwareError` — ошибки оборудования (порог: 50 подряд)
  - `DatabaseError` — ошибки БД (порог: 10 подряд)
- Обычные ошибки логируются и система продолжает работу

#### Graceful shutdown
- **Принудительный сброс всех выходов** при завершении (`Ctrl+C`, SIGTERM)
- Метод `_reset_outputs(force=True)` работает даже если оборудование недоступно
- Порядок: остановка контроллера → сброс выходов → отключение устройств → закрытие БД

#### WebSocket
- **Бесконечное переподключение** — `reconnectionAttempts: Infinity`
- Автоматический fallback на polling при разрыве соединения
- Восстановление real-time обновлений после переподключения
