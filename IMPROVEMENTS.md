# Предложения по улучшению stend_hardware

**Дата:** 10 июля 2026

---

## Критичные

### 1. Пароль в config.yaml открытым текстом
`password: "Alexej@12"` хранится в репозитории. Нужно убрать пароль из yaml, оставить только `.env`.

### 2. Нет тестов
Ни одного теста. Минимум: `verify_user`, `create_session`, state machine сценариев.

### 3. Создание нового соединения БД на каждый запрос
`get_connection()` открывает/закрывает psycopg2 на каждый вызов. Нужен connection pool (psycopg2.pool).

---

## Важные

### 4. Дублирование кода сценариев
Сценарии A, B, C имеют похожую логику (лампы, ошибка, сброс). Вынести в общий паттерн.

### 5. _main loop глотает исключения
`except Exception` в цикле `_run` логирует и продолжает. Критические ошибки должны останавливать систему.

### 6. Нет graceful shutdown
`Ctrl+C` может оставить конвейер включённым. Гарантированный сброс всех выходов при завершении.

### 7. WebSocket не reconnect
При перезапуске сервера клиент не переподключается автоматически.

---

## Удобства

### 8. Нет healthcheck endpoint
`/api/health` — uptime, статус БД, OWEN, камера.

### 9. Нет rate limiting на API
Открытый доступ к `/api/*` без ограничений.

### 10. Логи не ротируются по времени
Только по размеру (10 МБ). Нужна ротация по времени (ежедневно).

### 11. Нет backup/restore для БД
Экспорт в CSV/JSON по расписанию.

### 12. Конфиг не валидируется
Опечатка в config.yaml молча игнорируется. Нужна schema validation (pydantic/jsonschema).
